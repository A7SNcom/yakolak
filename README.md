# Yakolak

نسخة مرتبة لتشغيل ومعايرة لعبة ياكلك 3D على GitHub Pages.

## الملف المعتمد للتشغيل

افتح:

```txt
index.html
```

مسار التشغيل الحالي:

```txt
index.html
└─ app.js
   └─ app-clean-v026.js
      ├─ 9.stl
      ├─ 3.stl
      ├─ l.stl
      ├─ m.stl
      └─ s.stl
```

## لماذا يوجد `app-clean-v026.js`؟

هذا هو المحرك الحالي الذي وصلت فيه المعايرة لنتيجة ممتازة. لم يتم لمسه حتى لا نخسر المكتسبات.

`app.js` صار نقطة الدخول الرسمية فقط، عشان `index.html` ما يبقى مربوط باسم نسخة قديمة مباشرة.

## المعايرة الذهبية

تم أرشفة المعايرة الممتازة هنا:

```txt
archive/golden-calibration-v030.json
archive/golden-calibration-v030.js
```

القيم الذهبية:

```txt
تباعد الحجار = 48
اتجاه الأمام والخلف = 0
اتجاه اليمين واليسار = 90
ارتفاع الحجار LMS.py = 2
```

## قاعدة التطوير

لا نعدل على المعايرة الذهبية مباشرة.

أي تجربة جديدة تكون في نسخة جديدة، وبعد ما تثبت أنها أفضل بصريًا، ننقلها كمعايرة ذهبية جديدة.

## الملفات الأساسية

```txt
index.html      صفحة التشغيل
app.js          نقطة الدخول الرسمية
app-clean-v026.js المحرك الحالي المحفوظ
9.stl           بورد اللعب
3.stl           قواعد الاستعداد الخارجية
l.stl           حجر كبير
m.stl           حجر وسط
s.stl           حجر صغير
archive/        أرشيف المعايرة الذهبية
```
