# Yakolak

لعبة Yakolak ثلاثية الأبعاد على GitHub Pages.

## مسار التشغيل

```txt
index.html -> app.js -> src/app-live.js
```

## شكل المشروع

```txt
/
├─ index.html
├─ app.js
├─ version.json
├─ README.md
├─ src/
│  └─ app-live.js
├─ assets/
│  └─ models/
│     ├─ 9.stl
│     ├─ 3.stl
│     ├─ p.stl
│     ├─ l.stl
│     ├─ m.stl
│     └─ s.stl
├─ docs/
├─ archive/
└─ legacy/
```

## المعنى

```txt
src/      كود اللعبة الحالي
assets/   المجسمات والملفات التي يطلبها الموقع
docs/     التوثيق
archive/  النسخ الذهبية
legacy/   الملفات القديمة
```
