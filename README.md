# Yakolak

نسخة مرتبة لتشغيل ومعايرة لعبة ياكلك 3D على GitHub Pages.

## الملف المعتمد للتشغيل

افتح:

```txt
index.html
```

مسار التشغيل الحالي:

```txt
index.html
└─ app.js
   └─ app-clean-v026.js
      ├─ 9.stl
      ├─ 3.stl
      ├─ p.stl
      ├─ l.stl
      ├─ m.stl
      └─ s.stl
```

## لماذا يوجد `app-clean-v026.js`؟

هذا هو المحرك الحالي الذي وصلت فيه المعايرة لنتيجة ممتازة. لم يتم لمسه جذريًا حتى لا نخسر المكتسبات.

`app.js` هو نقطة الدخول الرسمية، عشان `index.html` ما يبقى مربوط باسم نسخة قديمة مباشرة.

## p.stl

تمت إضافة `p.stl` كعنصر مستقل قابل للمعايرة من زر الإعدادات ⚙.

له نفس معايرات المجسمات الأساسية:

```txt
px  Move X
py  Move Y
pz  Move Z
rx  Rotate X
ry  Rotate Y
rz  Rotate Z
```

بعد ضبط مكانه اضغط `Copy` أو `حفظ`، وارسلي الكود الناتج. ستجد داخله قسم:

```txt
p_model.alignment
```

## المعايرة الذهبية

تم أرشفة المعايرة الممتازة هنا:

```txt
archive/golden-calibration-v030.json
archive/golden-calibration-v030.js
```

القيم الذهبية:

```txt
تباعد الحجار = 48
اتجاه الأمام والخلف = 0
اتجاه اليمين واليسار = 90
ارتفاع الحجار LMS.py = 2
```

## قاعدة التطوير

لا نعدل على المعايرة الذهبية مباشرة.

أي تجربة جديدة تكون في نسخة جديدة، وبعد ما تثبت أنها أفضل بصريًا، ننقلها كمعايرة ذهبية جديدة.
