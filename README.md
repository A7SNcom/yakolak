# YAKOLAK

هذا هو المستودع الرسمي للعبة **ياكلك المبنية بمحرك Godot**.

## مصدر الحقيقة

- `main`: آخر نسخة منشورة ومعتمدة، وهي دائمًا نقطة البداية لأي تطوير جديد.
- `feature/...`: فرع مؤقت لمهمة واحدة، ويُنشأ من أحدث `main` فقط.
- `develop`: ليس مصدرًا مستقلًا للتطوير، ولا يُستخدم بدل النسخة المنشورة.
- `release/v2.9.0`: نقطة حفظ ثابتة للنسخة المنشورة بتاريخ 5 أغسطس 2026.
- `archive/threejs-v126`: أرشيف النسخة القديمة المبنية بـThree.js، وليس مسار تطوير.

## القاعدة الأساسية

نطوّر دائمًا فوق آخر نسخة منشورة ومعتمدة، وليس فوق نسخة تجريبية قديمة أو فرع جانبي.

لا يُعدّل `main` مباشرة. لكل مهمة فرع مؤقت يبدأ من أحدث `main`، ثم يُختبر على الجوال والكمبيوتر. بعد نجاحه واعتماده يُدمج إلى `main` ويُنشر، وبعدها تصبح هذه النسخة المنشورة هي أساس المهمة التالية.

## رابط التجربة

يجب إرسال رابط تجربة مباشر للمستخدم في **كل رد أو تقرير تطوير** حتى يستطيع التجربة فورًا.

- يجوز استخدام الرابط الرسمي أو أي رابط معاينة من Vercel.
- يجب توضيح هل الرابط نسخة منشورة معتمدة أم معاينة تحت التطوير.
- لا يجوز إرسال تقرير تطوير دون رابط قابل للفتح.

الرابط الرسمي الحالي:

https://yakolak.vercel.app/

## الحالة الحالية

النسخة المنشورة تحتوي على:

- لودر النجمة المعتمد.
- الطاولة والكاميرا والانترو المعتمد.
- اختيار حجر ووضعه في خانة قانونية بعد الانترو.

التطوير الجاري يُنفذ بهذا الترتيب فقط:

1. انتقال النجمة إلى الطاولة قبل الانترو.
2. إكمال المباراة المحلية والجولات.
3. اختيار اللون وعدد اللاعبين.
4. اللعب ضد الكمبيوتر.
5. الأونلاين.

## قاعدة العمل

مهمة واحدة = فرع واحد = Pull Request واحد = رابط تجربة واحد واضح.

لا تُنشأ فروع بأسماء أرقام أو «نسخة مثالية» أو «نسخة نظيفة». لا يُدمج أي عمل في `main` قبل نجاحه واختباره واعتماده.

راجع [`PROJECT_ORDER.md`](PROJECT_ORDER.md) قبل بدء أي تطوير، وراجع [`APPROVED_BASELINE_2.8.md`](APPROVED_BASELINE_2.8.md) قبل تعديل اللودر أو الطاولة أو الكاميرا أو الانترو.
