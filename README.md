# YAKOLAK — ياكلك

مستودع التطوير الحي للعبة ياكلك. المصدر الحالي أحدث `main`، والمحرك Godot.

## التحضير لإطلاق الجوال

[دراسة إطلاق App Store وGoogle Play](docs/research/store-launch/README.md): تدقيق المصدر، متطلبات المتجرين المحدثة، بدائل التغليف، مهام التنفيذ والقبول، وتجارب الرفض. الحزمة تخطيط فقط ولا تعني وجود تطبيق جوال جاهز. لحالة أونلاين Pages الحالية ارجع إلى [ONLINE_TRYSTERO](docs/ONLINE_TRYSTERO.md)؛ بعض الوصف التاريخي أدناه أقدم من هذا المسار.

## المعاينة

https://a7sncom.github.io/yakolak/

`main` → GitHub Actions → Godot Web Export → GitHub Pages.

Vercel ملغى بطلب المستخدم، وملف إعداداته محذوف. يجب ضبط Settings → Pages → Source على GitHub Actions إذا لم يكن Pages مفعّلًا.

GitHub Pages يعرض اللعبة الثابتة؛ غرف الأونلاين وواجهات `api/` تحتاج استضافة خادم منفصلة ولا تعمل على Pages وحده.

اقرأ `AGENTS.md` و`PROJECT_ORDER.md` قبل التعديل. PCLOCAL وThree.js والفروع القديمة مراجع تاريخية فقط.

## الإعداد البصري

واجهة `ui/visual-setup.mjs` و`ui/visual-setup.css` فوق طاولة Godot الفعلية، والجسر في `scripts/session_setup_visual.gd`. تُحفظ زاوية نهاية الانترو ويُضبط التكبير من حدود الطاولة ومقاس الشاشة. يبدأ الزائر بالجوال ثم الاسم غير المحفوظ لهذا الرقم على الجهاز، ويختار «غرفة جديدة» أو «انضمام لغرفة».

الغرفة الجديدة: لون بالإضاءة وتأكيد أسفل الطاولة، ثم «كم لاعب؟» والاختيارات أسفلها، ثم تعديل المقاعد بقوائم منسدلة خفيفة. الطلب ثلاثي الأبعاد فوق الطاولة ويختفي عند ظهور نافذة أخرى؛ المقاعد بلا بطاقات خلفية أو تكرار أرقام، ولا تظهر قبل اختيار العدد. بعد «ابدأ اللعب» يُسأل عن أشواط الفوز. الأسماء محفوظة لكل رقم في متصفح الجهاز فقط؛ لا تحقق SMS ولا إرسال للجوال إلى اللعبة أو الخادم.

اللعب المحلي والبوتات جاهزان. اختيار الأونلاين يوضح عدم توفر الخادم ويمنع بدء غرفة وهمية. زر المشاركة ينسخ رابطًا فقط عند وصول رمز غرفة حقيقي من الخادم؛ لا يُنشئ رمزًا محليًا وهميًا. حقل الانضمام يقبل الرمز أو رابط نفس المعاينة. خيارات الأجهزة المتصلة مجهزة لاستقبال أسماء حقيقية، لكن تشغيل الغرف والمقاعد على أجهزة متعددة يحتاج خادمًا ودعمًا في بروتوكول الغرفة قبل تفعيله.

بوابات النشر: `npm ci` ثم `npm run test:release` لعقود الغرف والقواعد والواجهة، تليها فحوص Godot headless لقواعد اللعب وتسليم الانترو ومسار الإعداد الفعلي قبل التصدير. يعتمد CI على ملف `package-lock.json`؛ jsdom أداة اختبار فقط ولا تدخل حزمة اللعبة.
