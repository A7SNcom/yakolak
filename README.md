# Yakolak

نسخة مرتبة لتشغيل ومعايرة لعبة ياكلك 3D على GitHub Pages.

## الملف المعتمد للتشغيل

افتح:

```txt
index.html
```

مسار التشغيل الحالي:

```txt
index.html
└─ app.js
   └─ app-clean-v026.js
      ├─ 9.stl
      ├─ 3.stl
      ├─ p.stl
      ├─ l.stl
      ├─ m.stl
      └─ s.stl
```

## لماذا يوجد `app-clean-v026.js`؟

هذا هو المحرك الحالي الذي وصلت فيه المعايرة لنتيجة ممتازة. لم يتم لمسه جذريًا حتى لا نخسر المكتسبات.

`app.js` هو نقطة الدخول الرسمية، عشان `index.html` ما يبقى مربوط باسم نسخة قديمة مباشرة.

## p.stl

تمت إضافة `p.stl` كمنظومة صفوف تلقائية.

المراكز الأربعة المعتمدة:

```txt
p-front  px 0    py 7  pz 85   rx -90  ry 0  rz 0
p-back   px 0    py 7  pz -85  rx -90  ry 0  rz 0
p-right  px 85   py 7  pz 0    rx -90  ry 0  rz 90
p-left   px -85  py 7  pz 0    rx -90  ry 0  rz 90
```

كل مركز ينتج 7 نسخ:

```txt
3 يسار + 1 وسط + 3 يمين = 7
4 جهات × 7 = 28 نسخة من p.stl
```

تباعد النسخ الافتراضي:

```txt
pSetup.gap = 28
```

وهو قابل للمعايرة من زر الإعدادات ⚙ باسم:

```txt
p.stl: تباعد السبعة
```

ويمكن معايرة كل صف لوحده من:

```txt
p أمام
p خلف
p يمين
p يسار
```

```txt

ارتفاع الحجار LMS.py = 2
```

## قاعدة التطوير

لا نعدل على المعايرة الذهبية مباشرة.

أي تجربة جديدة تكون في نسخة جديدة، وبعد ما تثبت أنها أفضل بصريًا، ننقلها كمعايرة ذهبية جديدة.
