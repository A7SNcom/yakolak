# Yakolak

لعبة Yakolak ثلاثية الأبعاد على GitHub Pages.

## الحالة المعتمدة الآن

```txt
index.html -> app.js -> src/app-live.js
```

المشروع مرتب الآن كبنية قابلة للتوسع بدل وجود ملفات كثيرة في الجذر.

## شكل المشروع

```txt
/
├─ index.html          صفحة الموقع الرئيسية
├─ app.js              ملف تشغيل صغير فقط
├─ version.json        ملف النسخة والتحديث
├─ README.md           شرح سريع للمشروع
├─ src/                كود التطبيق الحي
│  ├─ app-live.js
│  └─ assets/
│     └─ models/
│        ├─ 9.stl
│        ├─ 3.stl
│        ├─ p.stl
│        ├─ l.stl
│        ├─ m.stl
│        └─ s.stl
├─ docs/               توثيق المشروع
├─ archive/            نسخ ذهبية محفوظة
└─ legacy/             ملفات قديمة للرجوع فقط
```

## الملفات المهمة للمستخدم العادي

```txt
index.html      صفحة الموقع
app.js          يشغل التطبيق
src/            كود اللعبة الحالي
docs/           التوثيق
legacy/         ملفات قديمة لا تستخدم في التشغيل الحالي
```

## القيم الذهبية الحالية

```txt
stoneDistance = 48
threeRadius   = 135
pRadius       = 85
pPieceGap     = 11
```

## قاعدة مهمة

أي تطوير جديد يكون داخل `src/`، وأي ملف قديم لا نحتاجه للتشغيل يبقى داخل `legacy/` أو `archive/`.

## ملاحظة

النسخة الحالية للتصفح ممتازة، لذلك هذا الترتيب هدفه التنظيم فقط وليس تغيير شكل اللعبة أو طريقة اللعب.
