# YAKOLAK Free Play

This private-use variant starts directly on the approved YAKOLAK 2.9 table.

- Four fixed players and all 36 stones are always present.
- There is no intro, setup, player-count choice, colour choice, turn order, timer, score, win rule, or occupied-cell rule.
- Tap or click any stone, including one already moved, then tap or click any point on the board.
- `RESET` is the only interface button. It returns all stones to the four bases.

The source branch is intentionally separate from the current game so the main deployment is not changed.
