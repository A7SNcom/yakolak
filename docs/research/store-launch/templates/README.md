# قوالب التسليم للمطور والمالك

هذه القوالب مسودات داخل المستودع، **لا مواد منشورة أو إقرارات مكتملة**.

- [review-notes.en.md](review-notes.en.md): ملاحظات المراجع بالإنجليزية مع خيارات نطاق واضحة.

املأ placeholders، ثم تحقق من كل جملة على release build وأزل البدائل غير المختارة. لا ترفع رمز غرفة مؤقتًا أو token أو هاتفًا حقيقيًا إلى هذه الملفات العامة. البريد وURL والكيان والمعرفات placeholders عمدًا؛ يرفض gate التقديم قيمًا غير محسومة.
