# Yakolak — المرحلة المثالية V030

هذه هي المرحلة الذهبية الحالية للمشروع.

اسم المرحلة:

```txt
v030-board-nine-stones
```

تاريخ التوثيق:

```txt
2026-06-21
```

## الخلاصة البسيطة

وصلنا إلى توزيع صحيح للحجر:

1. داخل البورد: 9 أطقم حجر، شبكة 3×3.
2. خارج البورد: 4 قواعد خارجية.
3. كل قاعدة خارجية عليها 3 أطقم حجر: يسار، وسط، يمين.
4. مجموع أطقم الحجر:
   - داخل البورد: 9
   - خارج البورد: 12
   - الإجمالي: 21 طقم حجر

## قاعدة التباعد

التباعد المعتمد واحد ومشترك:

```txt
stone distance = 48
```

هذا الرقم هو المفتاح الأساسي للمرحلة.
أي تعديل مستقبلي يجب أن يبدأ من هذا الرقم ولا يغيره عشوائياً.

## ارتفاع الحجر

ارتفاع كل الحجر:

```txt
py = 2
```

ملاحظة مهمة:
في Three.js المستخدم هنا، الارتفاع المرئي هو محور Y، لذلك `py` هو الارتفاع.

## توزيع الحجر داخل البورد

داخل البورد شبكة 3×3 حول مركز البورد.

كل خانة تستخدم نفس التباعد 48.

صيغة الحساب:

```txt
x = gx * 48
z = gz * 48
```

حيث:

```txt
gx = -1 أو 0 أو 1
gz = -1 أو 0 أو 1
```

## توزيع الحجر على القواعد الخارجية

كل قاعدة خارجية فيها 3 أطقم حجر:

```txt
left / center / right
```

لكن اتجاه التكرار يختلف حسب القاعدة.

## اتجاه الأمام والخلف

القواعد:

```txt
3-front
3-back
```

الاتجاه:

```txt
mainDirectionDeg = 0
```

معناه التكرار يكون على محور X.

الحساب:

```txt
x = base.px + side * 48
z = base.pz
```

## اتجاه اليمين واليسار

القواعد:

```txt
3-right
3-left
```

الاتجاه:

```txt
sideDirectionDeg = 90
```

معناه التكرار يكون على محور Z.

الحساب:

```txt
x = base.px
z = base.pz + side * 48
```

## ملفات المجسمات المستخدمة

```txt
9.stl = البورد الأساسي
3.stl = القواعد الخارجية الأربع
l.stl = حجر كبير
m.stl = حجر متوسط
s.stl = حجر صغير
```

كل طقم حجر يتكون من:

```txt
l + m + s
```

## ملخص يفهمه أي شخص

اللعبة الآن فيها بورد في المنتصف وحوله أربع قواعد.
كل البورد مليان 9 أماكن حجر.
كل قاعدة خارجية عليها 3 أحجار.
المسافة بين الأحجار دائمًا 48.
ارتفاع الحجر دائمًا 2.
القواعد الأمامية والخلفية تنتشر يمين ويسار.
القواعد اليمين واليسار تنتشر فوق وتحت.
هذه هي المرحلة المثالية الحالية ولا يتم كسرها.
