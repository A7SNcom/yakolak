# Yakolak Project Constants

هذا الملف هو مرجع الثوابت المعتمدة للمشروع.
أي تعديل لاحق يجب أن يحافظ على هذه الثوابت ولا يغيرها إلا بطلب صريح من أحمد.

## النسخة المعتمدة الحالية

النسخة المعتمدة المستقرة هي التي تحتوي فقط على:

- `9.stl` = البورد / اللوح الأساسي
- `3.stl` = أربع قطع حول البورد

يمنع إدخال أو تعديل `l.stl` أو `m.stl` أو `s.stl` داخل هذه النسخة إلا كخطوة منفصلة وصريحة.

## الملفات الثابتة

```txt
9.stl
3.stl
```

## قاعدة مهمة عن محور Y

القيمة الحالية `py: 6` ليست هي الهدف النهائي هندسياً.
المفروض نظرياً أن يكون السطح أو قاع المجسم على `Y = 0`.
لكن الكود الحالي يعوض مشكلة تموضع/تطبيع المجسم، لذلك `py: 6` معتمدة مؤقتاً ولا يتم تغييرها عشوائياً.

## قواعد التطوير

1. لا يتم تغيير أماكن `9` أو أربع قطع `3` إلا بطلب صريح.
2. أي إضافة جديدة مثل `l/m/s` تكون فوق هذه النسخة ولا تمس الثوابت.
3. أي عنصر جديد يجب أن يكون له اسم واضح، وليس رقم STL فقط.
4. قبل أي تعديل كبير يجب الرجوع لهذا الملف.
5. لو ظهرت نتيجة كارثية، يتم الرجوع فوراً لنسخة `9 + 3` المعتمدة.
