# Asset Organization Plan

Goal: organize files without breaking the live game.

## Target folders

- game models: assets/models/game
- table models: assets/models/table
- table textures: assets/textures/table
- piece textures: assets/textures/pieces
- previews: preview
- old builds: archive/old-builds
- old experiments: archive/experiments
- legacy assets: archive/legacy-assets

## Rule

Move active assets only together with path updates in the runtime file.
