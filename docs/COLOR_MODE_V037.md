# Color Mode v037

## الحالة

```txt
v037-color-controls-only
```

هذه النسخة تعرض ألوان فقط ولا تعرض أي معايرات مواقع.

## عناصر الألوان

```txt
base     = لون البورد 9.stl وكل قواعد 3.stl
p        = لون كل قطع p.stl
right    = لون حجار قاعدة اليمين
left     = لون حجار قاعدة اليسار
front    = لون حجار قاعدة الأمام
back     = لون حجار قاعدة الخلف
```

## حجار البورد

حجار البورد مخفية بصريًا.

لكن مواقعها محفوظة في المخرجات:

```txt
board_stones.positions
```

## ممنوع في هذا الوضع

```txt
معايرة مواقع
معايرة مسافات
معايرة كل جهة
سلايدر للتباعد
```

## الواجهة

زر الإعدادات يفتح دوائر ألوان مناسبة للجوال.

الضغط على الدائرة يفتح اختيار اللون.
