# Yakolak — قواعد المشروع المعتمدة

هذا الملف هو المرجع قبل أي تعديل. هدفه منع الرجوع لنسخ قديمة أو تخريب الثوابت التي تم الوصول إليها بعد تجارب كثيرة.

## 1. المصدر الوحيد للحقيقة

بعد استرجاع النسخة المنشورة، المصدر المعتمد هو GitHub:

```txt
branch: main بعد اعتماد طلب الاسترجاع
version: v092-calibration-tutorial-fixes
build: 92
```

مسار التشغيل:

```txt
index.html
  -> app.js
    -> src/app-game-v085.js
```

ممنوع إعادة `app-prod-stage1.js` أو أي ملف قديم ليصبح نقطة التشغيل دون مقارنة واختبار صريح.

## 2. قبل أي تعديل

```txt
1. اقرأ README.md وهذا الملف.
2. افتح فرعًا مستقلًا.
3. افحص معاينة Vercel الحالية.
4. حدّد عنصرًا واحدًا أو مجموعة مترابطة بوضوح.
5. لا تستبدل أصلًا موجودًا بحل تجريبي.
6. لا تدمج إلى main قبل نجاح المعاينة.
```


## 4. الثوابت المقفلة

```txt
D  = 48
R3 = 135
A      مواضع البورد وقواعد اللاعبين
WALL   مواضع بداية قواعد الانترو
T      توقيتات الانترو
ORDER  ترتيب الألوان
```

لا تغيّر هذه القيم إلا بطلب مباشر، مع لقطة قبل وبعد واختبار لكل لون وحجم.

## 5. الطاولة والخامات

النسخة 92 تستخدم:

```txt
assets/models/table.svg
```

وتستخدم خرائط الطاولة الأصلية:

```txt
Mars Angled Stump Side Table 30x30x45_Albedo.png
Mars Angled Stump Side Table 30x30x45_Normal.png
Mars Angled Stump Side Table 30x30x45_Roughness.png
```

ممنوع:

```txt
- استبدال الطاولة بصندوق إلا كحل احتياطي عند فشل التحميل.
- توليد خامة عشوائية بدل الخرائط الموجودة.
- الرجوع إلى OBJ القديم باعتباره النسخة الحالية.
- تغيير أبعاد الطاولة دون فحص تماس البورد مع سطحها.
```

## 6. قواعد اللعب الحالية

النسخة 92 تحتوي:

```txt
- اختيار لون اللاعب.
- اختيار عدد اللاعبين.
- خصوم آليون.
- سحب واختيار الأحجام.
- مؤقت للدور.
- ثلاث طرق للفوز.
- نقاط وجولات.
- شرح تفاعلي.
- معايرة للمشهد والإضاءة والخامات.
```

أي تطوير أونلاين يجب أن يفصل بين:

```txt
حالة اللعبة الموثوقة على الخادم
العرض والحركة ثلاثية الأبعاد في المتصفح
```

ممنوع اعتبار حالة المتصفح وحدها مصدرًا موثوقًا للعب الجماعي.

## 7. واجهة المعايرة

المسار:

```txt
GET  /api/calibration
POST /api/calibration
```

المتغيرات:

```env
TURSO_DATABASE_URL
TURSO_AUTH_TOKEN
CALIBRATION_ADMIN_TOKEN   اختياري
```

عند تعذر قاعدة البيانات، يجب أن تستمر اللعبة بالإعداد الافتراضي دون شاشة سوداء.

## 8. النسخ والكاش

أي تغيير ظاهر للمستخدم يتطلب رفع BUILD في:

```txt
index.html
app.js
version.json
src/app-game-v085.js
```

ويجب تحديث `version.json` بوصف واضح، ثم اختبار رابط معاينة Vercel.

## 9. الاختبارات الدنيا قبل الدمج

```txt
- الصفحة تحمل دون أخطاء تشغيل.
- شاشة التحميل تصل إلى 100% وتختفي.
- المجسمات والخط والطاولة والخامات تعود بنجاح.
- اختيار الألوان وعدد اللاعبين يعمل.
- الأحجام الثلاثة قابلة للاختيار والوضع.
- طرق الفوز الثلاث تعمل.
- الجولات والنقاط والمؤقت تعمل.
- GET /api/calibration يعيد JSON صحيحًا.
- العرض يعمل على شاشة جوال وشاشة كمبيوتر.
- لا توجد أسرار أو رموز دخول داخل المستودع.
```
