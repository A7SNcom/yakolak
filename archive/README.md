# Yakolak Archive

هذا المجلد للأشياء التي لا نريد استخدامها يوميًا، لكن لا يجوز ضياعها.

## الملفات المهمة

### `golden-calibration-v030.json`
الأرشيف الرسمي للمعايرة الممتازة.

### `golden-calibration-v030.js`
نفس المعايرة بصيغة JavaScript سهلة النسخ.

## قاعدة مهمة

لا يتم تعديل المعايرة الذهبية إلا بعد اختبار بصري واضح ونتيجة أفضل منها.

القيم الذهبية الحالية:

- تباعد الحجار: `48`
- اتجاه الأمام والخلف: `0`
- اتجاه اليمين واليسار: `90`
- ارتفاع الحجار: `LMS.py = 2`
- البورد: `9.stl`
- القواعد الخارجية: `3.stl`
- الحجار: `l.stl`, `m.stl`, `s.stl`
