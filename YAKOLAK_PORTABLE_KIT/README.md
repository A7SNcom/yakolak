# YAKOLAK Portable Kit — Historical Reference

Status: **HISTORICAL / READ-ONLY**.

This directory preserves legacy assets and rebuild-reference material. Its former “Definitive Rebuild Guide” and detailed acceptance contract remain available in Git history, but they are not the implementation source of truth and must not be used as build, deploy, rollback, recovery, or executable fallback instructions.

Current operational source of truth is the latest GitHub `main` Godot project. Publish only through:

`main` → `YAKOLAK Flash Publish` → Godot Web export → `[flash-ready]` → Vercel → https://yakolak.vercel.app/

PCLOCAL, Three.js, old framework/runtime chains, and historical branches are reference-only. Do not copy or activate them as an alternative implementation path.

The asset files under this directory may still be inspected as historical design/reference evidence; they do not override `AGENTS.md`, `PROJECT_ORDER.md`, or current `main`.
