# YAKOLAK vNext — Clean Foundation

هذه المساحة هي نقطة البداية النظيفة للنسخة الجديدة من «ياكلك».

## حالة هذه المرحلة

- تحضيرية فقط.
- لا يتم تحميل أي ملف من `vnext/` داخل النسخة الحالية.
- لا تغيير على Production أو Build 126.
- لا إعادة كتابة للقواعد أو المشهد الآن.
- الهدف هو تثبيت التنظيم، أسماء الحالات، حدود المسؤوليات، وخطة الانتقال قبل كتابة الكود.

## لماذا مساحة جديدة؟

النسخة الحالية تطورت تدريجيًا من ملفات أقدم، ثم أضيفت مراحل متتابعة من v112 إلى v126. هذا حافظ على الاستقرار، لكنه أنتج طبقات تعتمد على wrappers وruntime patches وواجهات عامة متعددة. النسخة الجديدة ستحتفظ بما نجح، وتعيد بناءه داخل بنية واحدة واضحة بدل استمرار التراكم.

## المبادئ الثابتة

1. **مصدر حالة واحد:** كل وضع ظاهر للمستخدم يمثله State معروف.
2. **مدير كاميرا واحد:** لا تحرك أي ميزة الكاميرا مباشرة.
3. **قواعد لعب نقية:** القواعد لا تعرف Three.js أو DOM أو الشبكة.
4. **أحداث واضحة:** الإدخال ينتج Actions، والحالة تحدد النتيجة، ثم العرض ينفذها.
5. **أونلاين ومحلي بنفس القواعد:** الاختلاف في مصدر الأوامر والمزامنة فقط.
6. **الجوال مسار أساسي:** ليس نسخة مصغرة من الكمبيوتر.
7. **الحركة قابلة للمقاطعة:** الانتقالات تعرف كيف تتوقف أو تكمل أو تستبدل بأمان.
8. **Reduced Motion جزء من التصميم:** لا يضاف لاحقًا كاستثناء.
9. **كل مرحلة صغيرة وقابلة للاختبار:** لا تطوير شامل دفعة واحدة.
10. **لا Globals خفية ولا تعديل نصي لملفات قديمة:** الربط يتم عبر Imports وعقود معلنة.

## قرار هذه المرحلة

لا يبدأ تنفيذ vNext قبل اعتماد:

- قائمة الحالات والوضعيات.
- أسماء الحركات والانتقالات.
- ملكية كل مسؤولية.
- حدود القواعد والشبكة والعرض.
- أول Slice صغير سيتم بناؤه دون ربطه بالنسخة الحالية.
