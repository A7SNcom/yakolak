# Game

هذه الوحدة هي المصدر الوحيد لقواعد «ياكلك».

## المجلدات المخططة

```text
game/
├─ board/
├─ pieces/
├─ moves/
├─ turns/
├─ wins/
├─ rounds/
├─ match/
├─ bot/
└─ contracts/
```

## المسؤوليات

- إنشاء اللوحة.
- التحقق من المخزون والحركة.
- تطبيق الحركة.
- تحديد الفوز والتعادل.
- تحديد اللاعب التالي القادر على اللعب.
- تدوير بداية الجولة.
- تحديث نتائج الجولات والمباراة.
- توفير واجهة Bot تعتمد على الحالة والأوامر نفسها.

## خصائص مطلوبة

- Pure Functions قدر الإمكان.
- حتمية وقابلة لإعادة التشغيل.
- لا DOM أو Three.js أو Network.
- نفس الوحدة تستخدم محليًا وفي الخادم.
- لا تعتمد على أسماء مرئية للمستخدم؛ تستخدم IDs ثابتة.

## قاعدة التوافق

يبدأ التنفيذ من عقود `game-rules-v126.js` الناجحة، ثم توسع بعقود الجولات والمباراة دون نسخ منطق متوازٍ.
