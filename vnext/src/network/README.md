# Network

هذه الوحدة تحول الأونلاين إلى Adapter واضح حول نفس قواعد اللعب، بدل إنشاء لعبة ثانية.

## المجلدات المخططة

```text
network/
├─ rooms/
├─ identity/
├─ transport/
├─ sync/
├─ reconnect/
├─ commands/
└─ server-contracts/
```

## المسؤوليات

- قائمة الغرف المسماة.
- إنشاء الغرفة ومعاينتها والانضمام والمغادرة.
- حفظ الهوية الآمنة واستعادة الجلسة.
- إرسال Commands واستقبال Network Events.
- version conflict وretry/backoff.
- تجميد الإدخال وقت الانقطاع.
- مطابقة الحالة المحلية مع Snapshot موثوق.

## حالات الغرفة الأساسية

- `waiting`
- `playing`
- `finished`
- `cancelled`

## قواعد ثابتة

- الخادم صاحب القرار في الحركة والدور والفوز والنتيجة.
- العميل لا يعرض حركة نهائية قبل قبولها، ويمكنه عرض Preview فقط.
- Token لا يوضع في URL.
- استعادة الاتصال لا تعيد تشغيل رحلة الدخول إذا كانت المباراة قائمة.
- المزامنة لا تحرك الكاميرا مباشرة؛ ترسل Event للحالة.
- Local وOnline يستخدمان Game Commands وGame Results نفسها.
