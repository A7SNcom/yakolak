# Thmanyah Sans source

UI font: `thmanyahsans-Regular.otf` (Thmanyah Sans / خط ثمانية الرقمي).

Official font page: https://font.thmanyah.com/

The reproducible web build fetches the font from a pinned public copy at commit `1f9055ae105e6679d95f919b95b355baa5bfb43d` and verifies Git blob SHA `ca891297805da60b4b4e6d3a6f02cd7c0f2f33b7` before Godot export.
